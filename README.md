Fake News Detection Using Machine Learning

Project Overview
A machine learning-based application that identifies whether a news article is Fake or Real using Natural Language Processing.

Technologies Used
Python | Pandas | NumPy | Scikit-learn | TF-IDF | Passive Aggressive Classifier | Matplotlib | Seaborn

Dataset
Fake and Real News Dataset from Kaggle: Download Dataset

Key Features
Fake and Real news classification
Text preprocessing and TF-IDF feature extraction
Machine learning model training
Confusion matrix visualization
Performance evaluation

Model Performance
Test Accuracy: 98.81%
Evaluation Metrics: Precision, Recall and F1-score.
Results are based on the current train-test split and may vary with different preprocessing or data splits.
